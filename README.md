# Semi-Automated Scouting with AI

A data analysis project applying the Moneyball concept to Brazilian football. It crosses player performance stats with market value to identify undervalued players and group playing style profiles.

## Data
Football Data from Transfermarkt (Kaggle) - github.com/dcaribou/transfermarkt-datasets

## Status
🚧 In development - data exploration phase

## Scope and Limitations

This project currently covers only the Brazilian Série A (2025 season), using
data from the "Football Data from Transfermarkt" dataset. This dataset does not
include Copa do Brasil, Libertadores, or other continental competitions for
Brazilian clubs.

## Next Steps

- Expand coverage to Copa do Brasil and Libertadores using additional data sources
- Build cost-benefit metrics combining performance and market value
- Apply clustering to identify player profiles
